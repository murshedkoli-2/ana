# 📹 Video Admin — Content Management & Video Operations Dashboard

[![Next.js](https://img.shields.io/badge/Next.js-15.0-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![Drizzle ORM](https://img.shields.io/badge/ORM-Drizzle-C5F74F?style=for-the-badge&logo=drizzle)](https://orm.drizzle.team/)
[![PostgreSQL](https://img.shields.io/badge/Database-Neon_Postgres-00E599?style=for-the-badge&logo=postgresql)](https://neon.tech/)

A high-performance administrative dashboard for digital video content management, video categorization, metadata editing, and media publishing workflows built with **Next.js** and **Drizzle ORM**.

---

## 🌟 Features

- **🎬 Video Catalog Management**: Add, update, organize, and categorize media assets with custom thumbnails and metadata.
- **⚡ Drizzle ORM + Neon Database**: Type-safe, ultra-low latency SQL queries powered by Drizzle ORM and Neon Serverless.
- **📊 Publishing Pipeline**: Status workflows (Draft, Scheduled, Published, Archived) with batch editing capabilities.

---

## 🚀 Quickstart

```bash
git clone https://github.com/murshedkoli-2/ana.git
cd ana
npm install
npm run dev
```
